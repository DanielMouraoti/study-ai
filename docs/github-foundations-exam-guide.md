# 🎓 Guia: Como Agendar o Exame GitHub Foundations com Voucher (GitHub Education)

> **Público-alvo:** Estudantes cadastrados no programa [GitHub Education – Foundations Certificate](https://education.github.com/experiences/foundations_certificate).

---

## Pré-requisitos

- Conta GitHub vinculada ao **GitHub Student Developer Pack** (status de estudante verificado).
- Acesso ao portal [education.github.com](https://education.github.com/experiences/foundations_certificate).

---

## Passo a Passo

### 1. Obtenha seu voucher

1. Acesse [education.github.com/experiences/foundations_certificate](https://education.github.com/experiences/foundations_certificate) com sua conta GitHub.
2. Confirme que o seu status de estudante está ativo (você pode verificar em [education.github.com](https://education.github.com)).
3. Clique em **"Get your free exam voucher"** (ou link equivalente exibido na página).
4. **Copie o código do voucher** exibido. Guarde-o com segurança — cada voucher é de **uso único**.

> 💡 Se o botão de voucher não aparecer, verifique se seu Student Developer Pack foi aprovado e se sua conta de e-mail institucional está confirmada.

---

### 2. Acesse o portal de agendamento (PSI Online)

1. Abra [examregistration.github.com](https://examregistration.github.com/) — é o portal oficial da PSI, parceira do GitHub para aplicação do exame.
2. **Crie uma conta** na PSI ou faça login se já tiver uma.
3. Use o **mesmo e-mail** vinculado ao seu GitHub Education sempre que possível.

---

### 3. Encontre o exame GitHub Foundations

1. No portal PSI, busque pelo exame **"GitHub Foundations"**.
2. Clique em **"Schedule"** (Agendar).

---

### 4. Aplique o voucher e finalize o agendamento

1. Na tela de pagamento/checkout, localize o campo **"Voucher"**, **"Coupon Code"** ou **"Exam Voucher"**.
2. **Cole o código** copiado no passo 1 (evite digitar manualmente para não incluir espaços extras).
3. Clique em **"Apply"** para aplicar o desconto — o valor deve ser zerado.
4. Confirme o pedido para prosseguir.

---

### 5. Escolha data, horário e formato

| Formato | Descrição |
|---|---|
| **Online Proctored** | Realizado em casa, com câmera e monitoramento remoto. Exige ambiente silencioso e sem interrupções. |
| **Test Center** | Realizado presencialmente em centro de provas parceiro. |

1. Selecione o formato preferido.
2. Escolha uma **data e horário** disponíveis no calendário.
3. Confirme o agendamento.

---

### 6. Aguarde a confirmação

- Você receberá um **e-mail de confirmação** com os detalhes da prova e instruções de acesso.
- Para provas **Online Proctored**: teste seu computador antecipadamente seguindo as instruções do e-mail (câmera, microfone, navegador compatível).
- Chegue ou conecte-se **15 minutos antes** do horário agendado.

---

## ⚠️ Cuidados Importantes

- **Validade do voucher:** Verifique a data de expiração — vouchers vencidos não podem ser reativados.
- **Uso único:** O voucher é válido para **uma única tentativa** de agendamento; não é transferível nem reembolsável.
- **Antecedência mínima:** Agende com **pelo menos 24 horas** de antecedência.
- **Exame correto:** Confirme que o voucher é específico para *GitHub Foundations* (não para outro exame GitHub como GitHub Actions ou GitHub Advanced Security).
- **Documento com foto:** Tenha em mãos um documento de identidade válido com foto no dia do exame.

---

## 🆘 O Voucher Não Funcionou?

| Problema | O que fazer |
|---|---|
| Código inválido | Verifique se copiou o código completo, sem espaços extras. |
| Voucher já utilizado | O voucher só pode ser usado uma vez. Contate o suporte do GitHub Education. |
| Exame não encontrado | Certifique-se de estar no portal correto: [examregistration.github.com](https://examregistration.github.com/). |
| Erro no checkout | Tente outro navegador ou modo de navegação privada. |
| Problema persistente | Abra um chamado em [support.github.com](https://support.github.com) descrevendo o erro. |
