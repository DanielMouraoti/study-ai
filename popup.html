🎓 GitHub Foundations

Como agendar sua prova usando o voucher do GitHub Education

1
Obtenha seu voucher

Acesse GitHub Education – Foundations Certificate com sua conta GitHub vinculada ao programa Student Developer Pack. O voucher gratuito ficará disponível na página após validação do seu status de estudante.

2
Copie o código do voucher

Na página do GitHub Education, clique em "Get your free exam voucher" (ou link equivalente) e copie o código exibido. Guarde-o com segurança — cada voucher é de uso único.

3
Acesse o portal de agendamento

Vá para examregistration.github.com (plataforma PSI Online, parceira do GitHub). Crie uma conta ou faça login.

4
Selecione o exame e aplique o voucher

Encontre o exame "GitHub Foundations" e clique em "Schedule". Na tela de pagamento/checkout, localize o campo "Voucher / Coupon Code" e cole o código copiado. Clique em "Apply" para zerar o valor.

5
Escolha data, hora e formato

Selecione entre Online Proctored (câmera e ambiente controlado em casa) ou Test Center (presencial). Escolha o horário disponível e confirme o agendamento.

6
Confirme e prepare-se

Você receberá um e-mail de confirmação com instruções. Chegue 15 minutos antes (ou conecte-se antes) e certifique-se de ter documento com foto e ambiente sem interrupções (para provas online).

⚠️ Cuidados importantes

  • Verifique a data de validade do voucher — vouchers expirados não podem ser reativados.
  • Use copiar e colar para o código do voucher e evite espaços extras.
  • Agende com pelo menos 24 horas de antecedência.
  • O voucher é válido para uma única tentativa; não é reembolsável.
  • Confirme que o voucher é específico para o exame GitHub Foundations.

🆘 Voucher não funcionou?

  • Verifique se o voucher já foi utilizado em outra tentativa.
  • Certifique-se de estar logado no portal PSI com o mesmo e-mail do GitHub Education.
  • Entre em contato com o suporte do GitHub Education via support.github.com.
  • Para problemas no portal de exame, contate o suporte da PSI diretamente.
